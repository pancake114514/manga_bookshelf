## 3. 页序与阅读状态

| 术语 | 定义 | 代码落点 |
| --- | --- | --- |
| **页序（sort_order）** | images.sort_order，整数，决定正文页顺序。读取一律 ORDER BY sort_order, filename（filename 仅作同号兜底）。**追加**导入的起点是 MAX(sort_order)+1 而非 COUNT(*)，删除过中间页也不会与已有页重号。存量页序不做全局重排。 | src-tauri/src/db.rs:855-868、src-tauri/src/db.rs:884-895、src-tauri/src/service.rs:726-729 |
| **自然排序（natural sort）** | 页序的生成规则：文件名降为小写后切段，数字段按数值比较、其余按字符比较，数字段整体优先于字符段；数值相同时用整串兜底保证确定性。效果：1.png、2.png、10.png 顺序正确，补零命名与字典序等价。 | src-tauri/src/file_ops.rs:19-38、src-tauri/src/file_ops.rs:42-64 |
| **阅读进度（last_read_idx）** | objects.last_read_idx，0 起页下标，表示「上次停留的页」。展示口径：进度% = min(100, round(idx/(image_count-1)*100))，且 image_count<2 或 idx<=0 时为 0（视为未读）；idx >= image_count-1 视为读完。写入有 400ms 防抖，退出阅读器时兜底再写一次。 | src-tauri/src/db.rs:123、src-tauri/src/commands.rs:474-482、frontend/src/utils.js:11-16、frontend/src/components/ObjectCard.vue:113-116、frontend/src/components/Reader.vue:186-191、453-460 |
| **页标签（page_idx）** | 书签指向的页下标，0 起；与 last_read_idx 同一坐标系（都受页序影响，因此重排页序会同时错位进度与书签）。 | src-tauri/src/db.rs:184、frontend/src/components/Reader.vue:19-21 |

## 4. 封面与缩略图

| 术语 | 定义 | 代码落点 |
| --- | --- | --- |
| **封面（cover_image）** | objects.cover_image 存**显式指定**的封面文件绝对路径。解决顺序：显式封面（文件存在）→ 该对象首图 → 再查一次 DB 首图 → 无。封面 URL 带 ?v=<路径摘要>，路径一变 URL 即变，用于绕过 WebView 缓存。 | src-tauri/src/service.rs:430-448、src-tauri/src/commands.rs:265-275、286 |
| **默认首图** | 未显式设置封面时，取该对象页序最小的图片（ORDER BY sort_order, filename 的第一张）作为封面。 | src-tauri/src/db.rs:502-529、src-tauri/src/service.rs:780-793 |
| **.thumb 封面** | 源目录里以 .thumb 开头的文件（如 .thumb.jpg、无扩展名的 .thumb）视为「已缩小的封面」：导入时复制进存储目录并优先记为封面，**不计入正文页**（collect_images 过滤以点开头的隐藏文件）。无扩展名时按文件魔数嗅探是否图片；伪 .thumb 被忽略并回退首图。该类封面在协议层直接出原图、不再走缩略图生成。 | src-tauri/src/file_ops.rs:105-155、src-tauri/src/service.rs:731-745、780-793、src-tauri/src/commands.rs:663-674 |

## 5. 库校验与维护

| 术语 | 定义 | 代码落点 |
| --- | --- | --- |
| **库校验（verify）** | 对账数据库记录与磁盘现状的**只读**操作：短锁取对象与图片快照，锁外扫盘，输出总对象数、缺失图片总数、未登记文件总数、异常对象列表、孤儿目录列表。 | src-tauri/src/service.rs:53-62、230-325 |
| **缺失图片（missing_images）** | images 表已登记、但 filepath 指向的文件不存在。目录整体丢失时，该对象全部已登记图片都计入缺失。 | src-tauri/src/service.rs:270-274、284-287 |
| **未登记文件（unregistered_files）** | 存储目录里存在、但 images 表中没有同名记录的受支持图片（比对粒度是**文件名**，不是完整路径）。产生原因多为外部手工拷入；修复动作是「补登记」，页序在本对象内从 MAX+1 起连续递增。 | src-tauri/src/service.rs:268-283、355-391 |
| **空对象** | 已无有效图片的对象：存储目录不存在，或全部已登记图片文件都不存在。修复动作是删除对象记录（**不删文件**），且判定在执行时复查。 | src-tauri/src/service.rs:393-416、frontend/src/components/LibraryDialog.vue:139-142 |
| **孤儿目录** | 图库根下不属于任何对象记录的顶层目录（跳过以点开头的项，如 .thumbcache）。**只报告不可修复**，用途是提示用户可另行导入。 | src-tauri/src/service.rs:303-316 |
| **修复计划（VerifyFixPlan）** | 用户勾选后提交给后端的三个对象 ID 列表：remove_missing（移除缺失图片记录）、register（补登记未登记文件）、remove_empty（删除空对象）。三类均幂等，执行顺序固定为 移除 → 补登记 → 删空。 | src-tauri/src/service.rs:64-81、327-423 |
| **库迁移（migrate）** | 把整库搬到新根：①短锁生成计划 + WAL checkpoint + 写 .bak 备份 → ②无锁 fs::rename 逐个移目录 → ③短锁单事务改库（storage_path/filepath/cover/storage_root）。失败按逆序把目录搬回；.bak 仅在成功时删除。目标目录重名自动加「 (1)」后缀。迁移期间导入/删除/修复被拒（migrating 独占位）。 | src-tauri/src/library_manager.rs:194-324、src-tauri/src/service.rs:96-109 |
