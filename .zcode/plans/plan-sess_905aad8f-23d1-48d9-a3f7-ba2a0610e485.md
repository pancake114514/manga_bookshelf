# MangaShelf 界面重构计划(feature/web-ui 分支)

## 目标

视觉焕新 + 结构收敛 + 新功能,三线并重;同时移除旧 PyQt6 栈。所有 AGENTS.md 定义的交互基准(等尺寸网格/封面 5:7/右出左入两阶段过渡/R-18 模糊/双主题即时切换)**语义全部保留,实现可重写**。**不新增任何 npm 依赖**(图标用内联 SVG,组件继续用 Naive UI——它本身就是现代扁平组件库,本次会扩大其使用面让全局观感统一)。

## 分阶段实施

### 阶段 1:移除旧栈(独立提交)
- 删除 `main.py`、`ui/`(9 个 PyQt6 文件)、`MangaShelf.spec`(其入口指向 main.py,打包方案待新栈稳定后重建)、`git_commit_result.txt`(误提交的临时文件,并加入 .gitignore)。
- `requirements.txt` 移除 PyQt6(保留 Pillow,缩略图仍用)。
- 最小文档同步:`README.md` 中「基于 PyQt6」等已失真的描述改为新栈;`AGENTS.md` 删除「ui/ 旧界面」一行。(web 栈依赖按你的选择不写入 requirements,venv 已装不受影响)

### 阶段 2:结构地基(令牌/常量/图标单一真源)
- 新建 `src/constants.js`:收敛 4 处重复的 `CATS/CAT_LABELS`,新增 `RATING_CAT='rating'` 等常量。
- **主题令牌单一真源**:`theme.js` 的两套令牌对象增加 CSS 变量映射,`App.vue` 用 `:style` 把 `--bg/--card/--text...` 绑定到 `.app-shell`,删除 styles.css 中手抄的 `.theme-dark/.theme-light` 变量块——Naive UI overrides 与 CSS 变量从此同源。
- 新建 `src/components/icons.js`:约 20 个扁平风格内联 SVG 函数组件(搜索/导入/编辑/删除/播放/锁/日月/星/网格/列表/设置等),替换全部 emoji 图标。
- 错误边界:`boot()` 失败显示错误态 + 重试按钮,替换现在的静默吞错。
- 对话框挂载收敛:ImportDialog/LibraryDialog 从 TopBar 上移到 App 层;删除死代码(`.card-enter/.card-leave`、`store.selectedFilterCount`、无引用的 `api.checkWritable/importFiles`)。

### 阶段 3:store 与 bug 修复
- **修复 `store.objects` 永远为空**:查询结果统一写回 `store.objects`,Bookshelf 只负责渲染,ImportDialog 的"追加到已有目录"下拉随之修复。
- **R-18 开关持久化**:boot 时从 config 恢复 `ui_r18`,切换时写回。
- 新增偏好持久化:`ui_sort`(排序键+方向)、`ui_density` 同机制存取。
- 抽出防抖搜索等小工具函数,TopBar 的 `document.querySelector` 裸查 DOM 改为 ref 引用。

### 阶段 4:书架视觉与功能(核心)
- **两阶段过渡重写**:保留"右出左入"语义,修 stagger 失效 bug(`anim-delay` 已计算但从未生效,实际所有卡片同时动画)——phase + delay 通过 props/style 直达卡片;`prefers-reduced-motion` 继续禁用。
- **排序**:名称/添加时间/页数/评分/阅读进度 + 升降序,客户端排序,偏好持久化。
- **密度三档**:紧凑/标准/大图(调整 grid minmax 与卡片元信息密度),偏好持久化。
- **多选模式**:工具栏进入选择态,卡片出现复选框,底部浮动操作条:批量打标签(循环 updateObject,带进度)、批量删除(复用现有确认对话框)、全选/取消。
- **评星打分**:卡片悬停与详情页显示 NRate(1-5 星),存为 `tags.rating: ['4']`;**后端零改动**(已核实 set_tags/序列化对类别透传);侧栏评分区勾选多档星级=「≥N 星」(复用 filters 同类别 OR 语义)。
- ObjectCard 视觉精修:统一令牌、R-18 徽标/锁罩保留、空态用 n-empty。

### 阶段 5:详情页与阅读器
- **详情标签联动筛选**:DirectoryView 标签 chip 可点击 → 写入 `store.filters` 并返回书架。
- 修复封面 cache-buster:DirectoryView 改用统一 cover_url,不再每次渲染 `Date.now()` 重拉。
- **阅读器增强**:双页对开模式(右起,两页并排)、适应页面/适应宽度/原始尺寸三种缩放、预加载窗口扩到 ±3、进度条硬编码纸感配色接入主题令牌、工具栏 hover 自动隐藏。
- EditDialog/ImportDialog 统一用 TagFields(补联想能力,消除两套标签编辑实现),两对话框加 NRate 评分输入。

### 阶段 6:唯一后端改动(单独提交)
- `api.py:287` 补 `ImportCancelled` 导入(目前该异常路径会 NameError,单行修复)。

## 验证

1. `venv/Scripts/python.exe -m pytest` — 核心 33 测试全程保持绿(证明核心未破坏);
2. `npm run build` + `scripts/verify_api.py` 端到端;
3. `--serve --port 8765` 浏览器模式逐项人工验证:双主题切换、筛选/搜索动画、导入(new/append)、编辑+评星、批量操作、删除、迁移、阅读器三视图;
4. `scripts/theme_check.cjs` 主题回归。

## 提交策略

按阶段约 7 次本地提交,遵循 `<type>: 中文描述` 风格(如 `feat: 书架排序/密度/偏好持久化`),**只 commit 不 push**,推送等你确认。临时/测试库一律用 `MANGASHELF_DB` 环境变量,不碰真实库。

## 已知小副作用(可接受)

- 评星值会进入关键词搜索范围(搜"4"可能命中 4 星对象),影响极小,后端 search 语义不动。
